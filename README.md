# นักสืบตัวจิ๋ว ตามหาของในบ้าน 🔎 (Little Detective Game)

เกมเว็บแอปพลิเคชันฝึกสายตาและการสังเกตสิ่งของในบ้านสำหรับเด็กเล็ก (เวอร์ชันท้าทาย 8 ด่าน) พัฒนาด้วย HTML5, Tailwind CSS, SVG และ Web Audio API พร้อมเสียงอ่านภาษาไทย (Thai Speech Synthesis)

---

## 🌟 ฟีเจอร์เด่น
1. **ครบทั้ง 8 ด่านสถานที่ต่าง ๆ ทั่วทั้งบ้าน**:
   - 🛏️ **ด่าน 1: ห้องนอน** (หมอนนุ่ม, ตุ๊กตาหมี, โคมไฟ)
   - 🛋️ **ด่าน 2: ห้องนั่งเล่น** (รีโมตทีวี, หมอนอิง, แจกันดอกไม้)
   - 🍳 **ด่าน 3: ห้องครัว** (แอปเปิ้ลสีแดง, แก้วน้ำสีฟ้า, ทัพพี)
   - 🛁 **ด่าน 4: ห้องน้ำ** (เป็ดยางสีเหลือง, แปรงสีฟัน, สบู่ก้อน)
   - 📚 **ด่าน 5: ห้องอ่านหนังสือ & โต๊ะทำงาน** (ลูกโลกจำลอง, แว่นตาอ่านหนังสือ, นาฬิกาทราย)
   - 🧸 **ด่าน 6: ห้องของเล่นมหาสนุก** (บล็อกไม้ตัวต่อ, รถของเล่นสีแดง, กลองของเล่น)
   - 🌳 **ด่าน 7: สวนหลังบ้านแสนร่มรื่น** (บัวรดน้ำ, ดอกทานตะวันยักษ์, พลั่วขุดดิน)
   - 📦 **ด่าน 8: ห้องใต้หลังคาปริศนา** (หีบสมบัติโบราณ, กล้องดูดาว, ตะเกียงแก้วโบราณ)
2. **ของเยอะขึ้นและท้าทายขึ้น**:
   - มีสิ่งของลวงตากว่า 80+ ชิ้นซ่อนอยู่อย่างแนบเนียน
   - คลิกที่สิ่งของลวงตาจะมีเสียงและข้อความบอกชื่อสิ่งของเพื่อเสริมสร้างคำศัพท์
3. **ระบบเสียงในตัว 100% ไม่พึ่งพาไฟล์ภายนอก**:
   - Web Audio API สร้างเสียง Chimes, Thud, Fanfare สดใหม่
   - Web Speech API อ่านออกเสียงคำสั่งภาษาไทย 🔊
4. **ระบบสะสมดาวและถ้วยรางวัล**:
   - สะสมดาวสูงสุด 24 ดวง (ด่านละ 3 ดวง)
   - เอฟเฟกต์ประกายดาวและพลุเฉลิมฉลองเมื่อพิชิตครบทั้ง 8 ด่าน
